# CSA61 - Digital Forensics and Cyber Crime Investigation

## Experiment 1
### Demonstration of Locard's Exchange Principle using File Metadata

### Aim
To demonstrate Locard's Exchange Principle using file timestamps (metadata) in Python.

### Description
This Python program reads the metadata of a file and displays:

- Creation Time
- Last Modified Time
- Last Access Time

These timestamps act as digital evidence, demonstrating that every interaction with a file leaves traces.

### Technologies Used
- Python 3
- os module
- time module

### How to Run

```bash
python locards_exchange_principle.py
